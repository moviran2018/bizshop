تنظیمات & اتصال سوپابیس

برای اتصال به دیتابیس واقعی، پروژه Supabase بسازید، سپس supabase/schema.sql را در SQL Editor اجرا کنید و کلیدها را اینجا وارد کنید. بدون سوپابیس هم تمام داده‌ها در مرورگر (LocalStorage) ذخیره میشود و سایت کامل کار میکند.

راهنمای دیپلوی روی Cloudflare Pages:
  1. پروژه را به GitHub پوش کنید
  2. Cloudflare Dashboard → Pages → Connect to Git → انتخاب ریپو
  3. Build settings: Framework preset = None, Build command = (خالی), Output = /
  4. Environment variables: VITE_SUPABASE_URL و VITE_SUPABASE_ANON_KEY را اضافه کنید
  5. Deploy — سایت با دامنه pages.dev بالا می‌آید + دامنه اختصاصی قابل اتصال
